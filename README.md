# Keyboard Language Hotkeys

AutoHotkey v2 scripts for direct Arabic and Turkish keyboard selection on Windows.

- Alt+Shift+A selects the existing Arabic (Syria) layout.
- Alt+Shift+T selects Turkish Q.
- Alt+Shift+E selects Turkish Q for Latin characters without installing an English layout.
- A brief language badge appears after clicking editable text areas.
- The PowerShell helper removes English, Saudi Arabic, and US keyboard layouts if Windows adds them back.

## Requirements

- Windows 10/11
- AutoHotkey v2
- Arabic (Syria) and Turkish keyboard layouts installed

Run `keyboard-language-hotkeys.ahk` with AutoHotkey v2. Keep the PowerShell file in the same folder.
